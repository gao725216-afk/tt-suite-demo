# TT Suite · Frontend Demo

A standalone static demo of the TT Suite timetable, task and growth-garden interface.

## Demo boundaries
- All initial tasks, events and completion records are fictional.
- Changes are stored only in the visitor's browser. Reset and export controls are available under Settings.
- No account login, cloud synchronization, AI service, attachment upload or WeChat service is connected.
- Do not enter private or sensitive information into a public demonstration.

## Run
Serve this directory with any static HTTP server. The entry is `index.html`; `mobile-preview.html` shows the same responsive app inside a phone-sized viewport. Relative asset URLs and query-string routes support GitHub Pages project paths.
